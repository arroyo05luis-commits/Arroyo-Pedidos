
# Sistema de Gestión de Pedidos - Arroyo Pedidos

## Autor
Arroyo Rojas Luisi Leao

## Descripción
Proyecto desarrollado para gestionar el cálculo de importes de pedidos de una empresa comercializadora de accesorios informáticos.

## Objetivo
Implementar un sistema que permita calcular el subtotal de los pedidos, determinar el costo de envío y obtener el total a pagar.

## Estructura del proyecto

- codigo/: contiene el código fuente del sistema.
- documentos/: contiene los requisitos del sistema.
- cambios/: contiene el registro de solicitudes de cambio e incidencias.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Visual Studio Code
